## Workflow

1. Download the song folder from the repo
2. Make your changes in your preferred charting software (EOF, Moonscraper, Reaper, etc.)
3. Test in a game of your choice (Clone Hero, YARG, etc.)
4. Submit a Pull Request with a description of your changes

---

## Picking Something to Work On

- Check the GitHub Issues for open tasks
- Refer to the progress report in the README for current status
- If you're unsure, feel free to pick any incomplete track and contribute what you can

---

## Ways to Contribute

### 🟢 Lyrics (Easy)
- Add or correct lyrics and timing
- Add phrase start/end markers
- No musical knowledge required
- Great starting point

---

### 🟡 Plastic Instruments (Intermediate)
- Drums (and sometimes Bass) charting
- Requires understanding of charting standards
- Includes creating all difficulties (lower difficulties are derived from Expert)

---

### 🔴 Vocals Pitch (Advanced)
- Add pitch data to existing lyrics
- Requires a trained ear or a reliable transcription source

---

### 🟣 Bonus: Harmonies, Rhythm, Keys, Pro Instruments
- Optional, not required for completion
- Not every song needs every feature
- Some songs do not have harmonies, rhythm guitar, or keys

**Requirements:**
- Rhythm / Keys: same requirements as 🟡 Intermediate
- Harmonies / Pro Instruments: same requirements as 🔴 Advanced
